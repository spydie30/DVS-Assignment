# Data Visualization & Analysis Dashboard (DVS Assignment) (Roll No. 2025em1300232)

An interactive analytics and visual exploration application built with **Streamlit** and powered by **`uv`**. This app analyzes vehicle registration trends, fuel classifications, maker analytics, and state-wise metrics using the `VAHAN_Dataset_Cleaned_Final.csv` dataset.


---

## 📊 Dataset Information

* **File Name:** `VAHAN_Dataset_Cleaned_Final.csv`
* **Description:** Contains cleaned registration records, vehicle categories, maker details, fuel types, state-level metadata, and temporal trends derived from the official VAHAN portal.
* **Storage Location:** Place `VAHAN_Dataset_Cleaned_Final.csv` .
